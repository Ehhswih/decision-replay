# 示例组合说明

`demo-trades.csv` 是**构造的匿名数据**：一位虚构的个人投资者在 2026 年 6 月到 9 月的 21 笔成交。股票和行情是真实的，每笔成交价都落在当天不复权日 K 的最高价和最低价之间；交易时间、数量、理由是编的，用来覆盖复盘里需要演示的几类情况。

| 股票 | 持仓段 | 设计要演示的点 | 关键的真实事件（来自扶摇异动解读） |
|---|---|---|---|
| 兆易创新 603986.SH | 06-22 买 → 07-01 加仓 → 07-20 卖 | 追涨（买入前 5 日涨幅 +43%）；无视当时已经发布的风险提示，回调加仓；写了 8% 止损但没执行；连续跌停后恐慌卖出，第二天涨停 | 06-30 起“公司提示回落风险”；07-02、07-16、07-17 跌停；07-21 涨停 |
| 赛力斯 601127.SH | 07-08 买 → 07-14 卖 | 过程合理、结果亏损：有计划、按计划止损；亏损来自买入之后才公布的业绩预亏 | 07-13 跌停：“半年度业绩预亏” |
| 宁德时代 300750.SZ | 06-03 买 → 09-09 卖 | 没有退出计划，亏损单拿了三个多月（处置效应的一半） | 09-08 大跌：“理想自研电池” |
| 中远海控 601919.SH | 06-30 买 → 07-07 卖 | 写了目标 15%，涨 5% 就卖了（处置效应的另一半：赚钱的单子拿不住）；之后到 08-24 又涨了约 24% | — |
| 比亚迪 002594.SZ | 06-03 买 → 07-16 卖 | 最大浮亏约 18%，回到成本价附近就卖（锚定成本价） | 07-02、07-03 大涨：海外销量新高 |
| 药明康德 603259.SH | 08-05 买 → 08-25 卖 | 理由有当时可知的公告支撑，写了目标和止损，按计划止盈。原本想用来说明“不是每笔都有问题”，但规则仍然判了追涨和追热点（买在涨停后一天，买入前一天热股排名第 4），过程评级是“过程一般” | 08-04 涨停：“业绩超预期、上调指引” |
| 寒武纪 688256.SH | 06-18 到 06-29 来回 3 次 | 6 个交易日里买卖 6 次（过度交易）；理由说“冲上热榜”，但买入前一天它的热股排名是 296 名，当天排名要第二天才公布 | 06-18 单日涨 14% |
| 新易盛 300502.SZ | 06-09 买 → 06-18 卖 | 持有期间除权（06-11 每股派 1 元、送转 0.4 股），不复权价格从 780 到 580 看起来亏了 26%，实际上算上送转股和分红是赚的；写的 10% 止损也不能按不复权价格判定 | 06-11 除权 |

组合层面：已平仓的亏损段平均持有时间明显长于盈利段，用来演示“处置效应”规则（B4）。
