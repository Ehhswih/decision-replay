# 演示视频录制脚本

视频画面是在线地址上的真实操作：脚本驱动无头 Edge，按旁白的节奏点击、滚动、输入，光标、点击波纹、字幕、高亮框都画在页面上，逐帧录下来；旁白用本机的中文声音工作室（Breeze TTS 2，CC0 音色“晨光”）合成，再按每段的开始时间混进视频。

| 文件 | 作用 |
|---|---|
| `segments.json` | 旁白稿：每句分成朗读文本（数字写成汉字）和字幕文本 |
| `tts.mjs` | 调本机声音工作室（`http://127.0.0.1:7865`）逐段生成旁白，写到 `audio/` |
| `record.mjs` | 录制，`--dry` 只在关键位置截图；动作按每句旁白的开始时间触发 |
| `build.mjs` | 裁出 1920×1080 的视口，编码成 H.264，混入旁白，输出 `demo.mp4` |
| `durations.json` | 提交版本那次生成的旁白时长（参考用，运行时读的是 `audio/durations.json`） |

```bash
node tts.mjs && node record.mjs --dry && node record.mjs && node build.mjs
```

需要本机装有 Edge、ffmpeg 和声音工作室。录制会在线上示例组合里写下一条“揭晓前的判断”和几条清单（属于这次录制用的临时访客）。
